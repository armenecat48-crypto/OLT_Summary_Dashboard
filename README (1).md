# OLT Inventory Dashboard

Dashboard ภาพรวมอุปกรณ์ OLT สำหรับผู้บริหาร สร้างจากไฟล์ Excel ตามข้อกำหนดใน `Skill_olt.md`
(OLT Excel to Executive Dashboard)

---

## 1. วัตถุประสงค์ (Purpose)

แปลงข้อมูล OLT Inventory จาก Excel เป็น dashboard ที่เรียบง่าย อ่านเข้าใจทันที เหมาะกับการนำเสนอผู้บริหาร โดยเน้น

- จำนวน OLT ทั้งหมด (Total OLT)
- การกระจายของ OLT ตามจังหวัด (OLT by Province)
- การกระจายของ OLT ตามรุ่น (OLT by Model)
- สัดส่วนรายจังหวัด (Provincial Share)

## 6. การปรับมาตรฐานข้อมูล (Normalization)

- ตัดช่องว่างหน้า/หลัง ช่องว่างซ้ำ และอักขระที่มองไม่เห็น
- แก้คำสะกดผิด `สุราษฎ์ธานี` (7 รายการ) → `สุราษฎร์ธานี`
- ชื่อรุ่นแปลงเป็นตัวพิมพ์ใหญ่ รูปแบบเดียวกัน (เช่น `MA5800-X2`)
- **สมุย** (15 OLT) ถือเป็นจังหวัดพิเศษ จึงแสดงแยกเป็นอีกกลุ่ม ไม่รวมกับสุราษฎร์ธานี

## 8. การออกแบบ Dashboard (Design)

เป็นไปตามหลักการสำหรับผู้บริหาร: เรียบง่าย ตัวเลขใหญ่ อ่านง่าย เหมาะกับจอ 16:9

```
┌─────────────────────────────────────────────────────────────┐
│  OLT INVENTORY DASHBOARD                  Total OLT: 566    │
├───────────────────────────────┬─────────────────────────────┤
│  OLT by Province (แท่ง)       │  OLT by Model (แท่ง)        │
├───────────────────────────────┴─────────────────────────────┤
│  OLT Distribution by Province (Donut + สัดส่วน %)           │
│  แสดง Top 6 จังหวัด + อื่นๆ                                 │
└─────────────────────────────────────────────────────────────┘
```

- ธีมมืดแบบ Glassmorphism พร้อมปุ่มสลับธีมสว่าง/มืด
- ป้ายกำกับสองภาษา ไทย / English
- ไม่ใช้กราฟ 3D, gauge, ตัวกรองซับซ้อน หรือตารางข้อมูลดิบ
- ไฟล์เดียว ไม่พึ่งไลบรารีภายนอก (กราฟวาดด้วย CSS/SVG)

## 9. วิธีใช้งาน (Usage)

1. ดาวน์โหลด `OLT_Dashboard.html`
2. เปิดด้วยเบราว์เซอร์ (Chrome, Edge, Firefox, Safari)
3. แนะนำให้แสดงผลเต็มจอ 16:9 เพื่อนำเสนอ

### การอัปเดตข้อมูล

เมื่อมี NE Report ฉบับใหม่ ให้ส่งไฟล์ Excel ใหม่มา แล้วสร้าง dashboard ซ้ำตามขั้นตอนในหัวข้อ 4
โดยใช้คอลัมน์ตามหัวข้อ 3
